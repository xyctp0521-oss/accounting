# 小羊记账

个人智能记账系统，支持多设备数据同步。

## 在线访问

部署到 GitHub Pages 后，访问地址为：

```
https://你的GitHub用户名.github.io/accounting/
```

## 功能

- 收支记录（日期、类型、分类、用户、金额、备注）
- 按用户筛选，顶部统计联动
- 图表可视化：支出分类饼图、每日趋势折线图、月度收支柱状图
- 智能分析：环比变化、异常支出、消费时间规律、储蓄率、节省建议
- CSV 导出
- 多设备同步：通过 Gitee 私有仓库 API 存储数据

## 多设备同步配置

1. 注册 [gitee.com](https://gitee.com)
2. 创建一个**私有仓库**（例如 `accounting`）
3. 生成**私人令牌**：头像 → 设置 → 私人令牌 → 生成新令牌，勾选 `projects` 权限
4. 打开记账页面，点右上角 **⚙ 同步**
5. 填入：
   - 仓库所有者：你的 Gitee 用户名
   - 仓库名：`accounting`
   - 文件路径：`data.json`
   - 私人令牌：刚复制的 token
6. 点 **保存配置**，数据会自动同步到 Gitee

之后任何设备打开同一个页面，都会自动从 Gitee 拉取最新数据。

## 本地开发

```bash
python3 -m http.server 8080
```

然后访问 http://127.0.0.1:8080

## 数据来源

2026 年数据来自 Excel 表格 `记账.xlsx`，按单元格背景色映射用户：

- 蓝色 → 小羊
- 白色 → 南瓜
- 粉红色 → 共同
